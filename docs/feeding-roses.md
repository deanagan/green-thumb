RULES

- Osmocote = September full dose, February light dose only
- Sudden Impact = October + January for west-facing roses only
- Liquid = monthly spring–summer for potted roses only
- Never apply all fertilisers in the same week
- Skip feeding during heatwaves
- Stop all fertilising from March onward
